# Passo a Byte

Trilha interativa para aprender Python no navegador: lições curtas, editor de código, execução real com Pyodide e feedback automático. Inclui os **Desafios do Robô**, em que você programa o Bit para atravessar labirintos e acompanha a execução passo a passo.

> Projeto em construção. Este README será completado ao longo das etapas.

## Stack planejada

- React + Vite + Tailwind CSS v4 (JavaScript)
- CodeMirror 6 · Pyodide em Web Worker · Canvas 2D · Zustand
- Vitest · GitHub Actions · Vercel
