titulo: Decidindo com if

exercicio:
  enunciado: |
    Leia a temperatura (número inteiro). Se ela for **maior que 30**, mostre `Calor!`.
    Caso contrário, o programa não mostra nada.
  codigo_inicial: |
    temperatura = int(input("Temperatura: "))
    print("Calor!")
  entrada: ["35"]
  testes:
    - tipo: saida
      nome: 35 graus mostra "Calor!"
      entrada: ["35"]
      esperado: Calor!
    - tipo: saida
      nome: 20 graus não mostra nada
      entrada: ["20"]
      esperado: ""
    - tipo: saida
      nome: Exatamente 30 graus não mostra nada
      entrada: ["30"]
      esperado: ""
      mensagem: '"Maior que 30" não inclui o próprio 30.'
  dicas:
    - "A estrutura é `if condição:` e, na linha de baixo, o comando recuado com 4 espaços."
    - "A condição é `temperatura > 30`."
  solucao: |
    temperatura = int(input("Temperatura: "))
    if temperatura > 30:
        print("Calor!")
  explicacao_solucao: |
    O `print` está **dentro** do `if` porque está recuado. Ele só roda quando `temperatura > 30`
    é `True`. Para 30 graus a comparação dá `False`, e o bloco é pulado.
---
Programas de verdade tomam decisões. O `if` ("se") executa um bloco de código **só quando**
uma condição é verdadeira:

```python
vidas = 0
if vidas == 0:
    print("Fim de jogo")
    print("Tente de novo")
print("Obrigado por jogar")
```

```text
Fim de jogo
Tente de novo
Obrigado por jogar
```

Três regras de escrita:

1. A linha do `if` termina com **dois-pontos** `:`.
2. O que pertence ao `if` fica **recuado** com 4 espaços (o editor faz isso sozinho depois do `:`).
3. A primeira linha sem recuo marca o fim do bloco: ela roda sempre.

Se `vidas` fosse `2`, só a última linha apareceria.
